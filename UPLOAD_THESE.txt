Security + bank binding update
==============================

Changes:
1. Admin login: removed demo credentials (admin/admin123) and empty username/password fields
2. Public claim + track pages: removed Admin Console / Finance Review links
3. Bank details: one mobile ↔ one bank account (mandatory for payout)
   - customer_bank_details.mobile_number is PRIMARY KEY (already)
   - same account number cannot be used on a different mobile
   - after claim submit, customer is directed to Track page to add bank

Customer bank flow:
  1. Submit claim on claim portal with contact mobile
  2. Open Track page with mobile + Submission ID
  3. Enter bank account (name, number, bank, branch)
  4. Saved permanently against that mobile — Finance uses it for payout bind
