FLASH-LOOP FIX + live URLs
==========================

Root cause of admin "flashing / refresh loop":
  On API 401 the page did location.reload() but left the bad token in
  localStorage → reload picked it up again → infinite flash.

Fix:
  admin/index.html + admin/finance.html now call clearSessionAndReload()
  which removes adminToken / financeToken from localStorage before reload.

URLs already filled:
  Worker:  https://customereward.slcantec.workers.dev
  Claim:   https://rewards.cloudebase.dpdns.org
  Admin:   https://admin.cloudebase.dpdns.org

Overwrite in repo:
  public/config.js, public/app.js, public/index.html, public/track.html
  admin/config.js, admin/index.html, admin/finance.html
  src/index.ts

After push: hard-refresh admin (Ctrl+Shift+R) or clear site data once
so any old invalid token is gone. You should land on the login screen
instead of a loop.

  ADMIN_JWT_SECRET
  FINANCE_JWT_SECRET
